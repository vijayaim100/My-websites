Install ExpensGlobe like an app.

ExpensGlobe is a Progressive Web App. Use it in your browser or install it on a supported phone or computer for quick access.

No traditional app-store download is required.

Android

  1. Open ExpensGlobe in Chrome.
  2. Tap the three-dot menu.
  3. Select Install app or Add to Home screen.

iPhone

  1. Open ExpensGlobe in Safari.
  2. Tap the Share button.
  3. Select Add to Home Screen.

Windows or Mac

  1. Open ExpensGlobe in Chrome or Edge.
  2. Click the browser install icon.
  3. Select Install ExpensGlobe.
